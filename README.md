# 補助導航 Welfare Guide — Claude Skill（免費）

家裡有人需要照顧、突然失業、房租付不出來的時候，很多人不知道可以申請什麼補助，也不知道要去哪裡問。這個 Skill 讓 AI 先問清楚你的狀況，列出「可能符合」的台灣補助與福利，說明去哪裡申請、要帶什麼、打電話可以怎麼說、沒過怎麼辦。

免費提供，給需要的人使用。它只是幫你整理方向，最後以政府窗口的審核為準。這個頁面的檔案就是完整版，可以直接下載。

## 中風速查：不用 AI 也能看

**在台灣，疑似中風先打 119，不要先下載或問 AI。** 人在其他地方，請打當地的急救電話。

- **離線看**：點「Code → Download ZIP」後解壓縮，雙擊根目錄的 `先看這頁.html`。不需登入、不需安裝 Skill、不消耗模型額度。也可直接讀 [純文字速查](先看這頁.txt)；官網連結需上網。
- **有 AI 額度時**：照下方安裝 Skill，說明現在是住院、準備出院、已返家或長期照顧，再請 AI 列出該階段的下一步、窗口和官方來源。額度快用完時，可請 AI 一次整理成一頁並存下來。

## 涵蓋的類別
- 長照服務（照顧、交通接送、輔具與居家無障礙、喘息服務）
- 身心障礙（生活補助、輔具、照顧服務）
- 經濟扶助（低收入戶、中低收入戶、急難救助）
- 老人津貼、育兒與托育、租金補貼、健保欠費協助

## 安裝
1. 按綠色的「Code」→「Download ZIP」，解壓縮。
2. 把裡面的檔案放進 `%USERPROFILE%\.claude\skills\welfare-guide\`（Mac：`~/.claude/skills/welfare-guide/`）。
3. 重新開啟 Claude Code，跟 AI 說你的情況。

## 限制
- 只涵蓋台灣的制度；內容是繁體中文。
- AI 只能說「可能符合」，結果以主管機關審核為準；不代辦申請。
- 制度和金額常改，一切以官網與窗口當下公告為準；各縣市可能不同。
- 不保證一定有效；AI 不一定每次都照做。
