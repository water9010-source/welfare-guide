# 補助導航 Welfare Guide — Claude Skill（免費）

需要幫忙，卻不知道該找誰？跟 AI 說你的狀況，它會告訴你這件事該找哪個官方窗口：哪個機關、哪個地方政府單位、電話和官方網站。

能不能申請、能領多少、要帶什麼，都由窗口回答。AI 不解釋資格，也不判斷你能不能領。

免費提供，給需要的人使用。這個頁面的檔案就是完整版，可以直接下載。

## AI 會怎麼做
- 有家暴、想不開、有生命危險等緊急狀況，第一句就給專線（110、113、119、1925）。
- 其他狀況：告訴你該找哪個窗口、電話、官方網站。
- 窗口的電話和網址都先打開官網核對過；區公所、縣市政府的電話各地不同，會請你打 1999 縣市民眾服務專線問。
- 不問身分證字號、帳號、密碼；不代你打電話或送件。

## 涵蓋的事情
長照、低收入戶與急難救助、身心障礙證明、失業給付、租金補貼、育兒津貼與托育補助、健保欠費、家庭暴力、想不開；不知道找誰時，請你打 1957 福利諮詢專線。

## 用 Copilot、ChatGPT、Gemini 等其他 AI 的人
1. 打開下載的檔案中的 SKILL.md，全選、複製，貼進對話框。
   不要只上傳壓縮檔，也不要只貼 LICENSE.txt，AI 會讀不到做法。
2. 第一句打：「照上面的規則當我的『補助導航』」。
3. 再說你的狀況。
- 這是貼上的做法，這些 AI 沒有逐一實測過。

## 安裝（Claude Code）
1. 按綠色的「Code」→「Download ZIP」，解壓縮。
2. 把裡面的檔案放進 `%USERPROFILE%\.claude\skills\welfare-guide\`（Mac：`~/.claude/skills/welfare-guide/`）。
3. 重新開啟 Claude Code，跟 AI 說你的狀況。
